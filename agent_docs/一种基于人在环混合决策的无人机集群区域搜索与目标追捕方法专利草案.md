# 说 明 书 摘 要
本发明公开了一种基于人在环混合决策的无人机集群区域搜索与目标追捕方法及系统，面向“区域搜索—任务目标分配—目标追捕”三阶段协同任务流程。所述方法在搜索阶段与分配阶段采用可解释的建模优化方法并支持人在环/环中决策，通过人机交互界面对搜索参数、匹配代价权重和分配结果进行确认与调整；在追捕阶段针对高动态对抗子任务，调用预训练的N对1多无人机目标追捕策略模型执行去中心化控制，并支持依据任务需求在多种决策倾向模型间切换。进一步地，本发明定义了任务目标池与无人机资源池的联动更新机制，建立了“搜索、跟踪、追捕、回切”状态机与追捕子任务触发条件，规定仅当被分配的搜索无人机重新稳定感知目标后启动追捕子任务环境，并给出异常场景下的回退与重分配流程。本发明在保持上层决策可解释性与人工可干预性的同时，提升了高动态追捕阶段的实时性与成功率，兼顾工程可控性和任务执行效能。

关键词：无人机集群；人在环；混合决策；任务分配；多智能体强化学习；目标追捕

S2：执行区域搜索预规划，生成用于覆盖任务区域的搜索航线，并允许使用者通过人机交互界面对搜索参数及预规划结果进行确认或调整；  
S3：基于任务目标池与无人机资源池执行任务目标分配，采用加权匹配代价与匈牙利算法求解目标分配结果，并允许使用者对代价权重和分配结果进行人在环/环中干预；  
S4：对每组分配结果执行状态切换，令对应Explorer进入跟踪状态，令对应Hunter进入待追捕状态；

S6：当追捕子任务结束后，更新任务目标池与无人机资源池，释放相关无人机并回切至搜索或待命航线，触发后续目标分配直至任务终止。

# 说 明 书
## 一种基于人在环混合决策的无人机集群区域搜索与目标追捕方法及系统

## 技术领域
本发明涉及无人机集群协同控制与智能决策技术领域，具体涉及一种面向区域搜索与目标追捕任务的、融合可解释优化决策与多智能体强化学习执行策略的基于人在环混合决策的方法及系统。

## 背景技术
现有无人机集群任务在工程实践中通常可抽象为“搜索—分配—执行”的阶段化流程。传统规则建模与优化方法在搜索和任务分配阶段具备较强可解释性，便于人工审查和参数化调整，但在高动态对抗场景下，决策模型构建难度大、泛化性不足，且实时重规划开销高。

另一方面，基于多智能体强化学习的策略模型在高动态博弈子任务中具有较好的实时决策能力和适应性，但其“黑盒”特征使得全流程完全依赖学习策略时，存在难以人工干预和难以解释的问题。

因此，需要一种兼顾上层可解释可干预与底层高动态执行能力的混合方法：在搜索、分配阶段保留人在环/环中优化决策机制，在追捕阶段调用预训练策略模型进行快速闭环控制，并支持按任务偏好切换不同决策倾向模型。

## 发明内容
### （一）发明目的
本发明的目的在于提供一种基于人在环混合决策的无人机集群区域搜索与目标追捕方法及系统，以解决现有技术中“传统方法实时性不足”与“纯学习方法可解释性不足”难以兼顾的问题。

### （二）技术方案
本发明采用如下技术方案：

S1：构建由Explorer、Hunter、Target组成的任务环境，初始化任务目标池与无人机资源池。  
S2：进行区域搜索预规划，生成功能上满足覆盖搜索的航线方案，支持使用者在执行前进行参数调节、结果复核与再规划。  
S3：在任务运行过程中，当发现新目标或资源释放时触发任务分配；通过匈牙利算法在多因素加权代价下求解Explorer/Hunter与Target匹配关系，并支持人工调整权重以改变分配倾向。  
S4：依据分配结果切换无人机状态，Explorer进入跟踪状态，Hunter进入待追捕状态。  
S5：当Explorer稳定感知目标后，启动N对1追捕子任务环境，调用预训练追捕策略模型执行去中心化追捕控制；系统支持在多种决策倾向模型间切换。  
S6：追捕结束后更新目标池与资源池，相关无人机回切搜索或待命状态，并触发后续分配，直至任务完成。

进一步地，所述S3中代价函数包含距离、目标价值、续航、任务切换惩罚、分配阈值约束等子项，每个子项权重可由使用者在线调节并保存为模板。  
进一步地，所述S5中追捕策略模型来自预先训练完成的模型库，模型库中不同模型体现不同决策倾向，可依据任务风险偏好、效率偏好或能耗偏好进行切换。  
进一步地，系统定义异常回退流程以处理“发现新目标但无空闲资源”与“跟踪中丢失目标”等场景，保障任务流程闭环。

### （三）有益效果
与现有技术相比，本发明具有以下有益效果：
1. 在搜索与分配阶段引入人在环/环中决策机制，增强方案可解释性、可审查性与可调节性。  
2. 在追捕阶段调用预训练策略模型处理高动态对抗子任务，提升实时决策能力与执行稳定性。  
3. 通过多因素代价权重调节与策略模型切换，实现“上层可控、下层高效”的混合决策闭环。  
4. 通过目标池/资源池联动更新与状态机回切机制，支持复杂任务流程中的异常恢复与持续执行。  
5. 不约束具体搜索航线几何形式，具备工程实现灵活性，便于在不同场景中迁移部署。

## 具体实施方式
以下结合附图和实施例对本发明作进一步说明。

### 实施例一：任务初始化与区域搜索预规划
步骤1：建立二维任务区域，设置任务总时长、步长间隔以及Explorer数量M、Hunter数量N和Target数量K。初始化任务目标池与无人机资源池。  
步骤2：执行覆盖式搜索航线预规划，输出每架Explorer的执行航线。航线规划算法可以为弓字形、栅格、分区回路或其他覆盖规划方式，本发明对此不作限制。  
步骤3：使用者在任务面板对覆盖率相关参数、边界安全参数、Hunter待命模式参数进行设置并确认；若不满足任务需求，可触发重规划。

在本实施例中，Hunter待命模式包括分散待命模式与分区伴随模式：
1. 分散待命模式：Hunter在各自待命航线上往返机动，形成较大空间覆盖。  
2. 分区伴随模式：Hunter按Explorer分组形成待命编队并跟随对应Explorer机动，以提升局部快速响应能力。

### 实施例二：任务分配与人在环权重调节
步骤4：任务运行后，Explorer持续感知目标并将目标信息写入任务目标池；当出现新目标或资源释放时触发任务分配。  
步骤5：构建基于匈牙利算法的匹配代价矩阵。代价至少包含：距离项、目标价值项、续航项、任务切换惩罚项以及阈值约束项。对超过距离阈值的无人机-目标组合置为不可分配。  
步骤6：根据目标价值为每个Target确定所需Hunter数量区间（至少1架，至多为预设上限），并为该目标匹配至少1架Explorer。  
步骤7：计算最优匹配后输出分配结果；使用者可在线调节各代价子项权重并重算，以实现决策倾向调整；可将当前权重组合保存为模板供后续任务复用。

### 实施例三：状态机切换、追捕启动门控与子任务执行
步骤8：对分配成功的无人机执行状态切换：Explorer由SEARCH切换至TRACK，Hunter切换至待追捕状态。  
步骤9：在TRACK阶段，Explorer持续向目标机动并更新目标状态；仅当Explorer进入有效感知范围且连续稳定更新达到门控阈值时，启动追捕子任务环境。  
步骤10：追捕子任务环境以当前Hunter与Target状态初始化，调用预训练N对1追捕策略模型执行去中心化控制；子任务结束后返回主任务环境并同步状态。

所述追捕策略模型由策略模型管理模块统一维护，至少包含两类不同决策倾向：
1. 效率优先模型：侧重缩短抓捕时间。  
2. 稳健优先模型：侧重安全间隔与能耗约束。  
系统可在子任务启动前或执行中依据任务指令切换模型，切换后继承当前环境状态并在下一控制周期生效。

### 实施例四：异常场景回退流程
A1：当Explorer A处于TRACK状态时发现新目标B，系统触发新增目标分配。若存在空闲Explorer，则分配Explorer B处理目标B；若无空闲Explorer，则该目标暂存于任务目标池等待资源释放后重分配。  
A2：若Explorer B在接近目标B过程中，目标B离开所有Explorer感知范围，视为追捕启动失败：Explorer B返回中断前搜索航点，关联Hunter回收为可用资源，目标B对应临时记录从任务目标池移除。

### 实施例五：任务闭环与终止
步骤11：每次追捕子任务结束后，更新任务目标池与无人机资源池；完成任务的Explorer返回搜索航线最近航点继续搜索，Hunter返回待命航线或待命编队。  
步骤12：资源池更新触发新一轮任务分配，形成“搜索—分配—追捕—回切”的闭环，直至达到任务完成条件或任务时长上限。
