# 说 明 书 摘 要
本发明公开了一种基于人在环混合决策的无人机集群区域搜索与目标追捕方法及系统，适用于由搜索无人机、追捕无人机和任务目标构成的集群协同任务。该方法将任务过程划分为区域搜索、任务目标分配和目标追捕三个层级任务：在区域搜索与任务目标分配任务中，采用可解释建模与优化求解，并提供人工确认、参数调节和结果复核的人在环/环中决策入口；在目标追捕阶段针对高动态对抗子任务，基于已训练的N对1追捕策略模型执行快速去中心化控制，并支持按任务需求在不同决策倾向模型间切换。方法进一步建立任务目标池与无人机资源池联动机制，定义搜索、跟踪、追捕与回切状态转换规则，并以“稳定感知后启动追捕子任务”作为门控条件，实现异常场景下的回退与重分配。该发明在保证上层决策可解释、可干预的同时，提高高动态追捕阶段的实时性与执行稳定性。

关键词：无人机集群；人在环；混合决策；匈牙利分配；多智能体强化学习；目标追捕

# 说 明 书
## 一种基于人在环混合决策的无人机集群区域搜索与目标追捕方法、系统、设备及存储介质

## 技术领域
本发明涉及无人机集群协同控制、任务规划与智能决策技术领域，尤其涉及一种在上层采用可解释优化、在下层采用强化学习策略执行的基于人在环混合决策的区域搜索与目标追捕方法及其系统实现。

## 背景技术
无人机集群任务通常呈现“搜索—分配—执行”的分阶段流程。现有传统优化方法在搜索和分配阶段具有可解释、可干预优势，但在高动态对抗执行阶段存在建模困难、实时重规划成本高、泛化能力不足等问题。

纯强化学习方法可通过策略推理提升动态场景响应速度，但在全流程应用中存在可解释性不足、人工干预能力弱等缺陷，难以满足工程应用中的安全审查和决策可控需求。

因此，亟需一种兼顾“可解释可干预”与“高动态实时执行”的混合决策技术方案。

## 发明内容
### （一）发明目的
本发明的目的在于提供一种基于人在环混合决策的无人机集群区域搜索与目标追捕方案，以在搜索和分配阶段保留人工可控性，在追捕阶段提升动态决策实时性与鲁棒性。

### （二）技术方案
本发明提供的方法包括：
1. 建立由Explorer、Hunter和Target构成的任务环境，维护任务目标池和无人机资源池。  
2. 在区域搜索阶段执行覆盖式预规划，允许使用者对规划参数与结果进行确认、修正和重规划。  
3. 在任务分配阶段基于匈牙利算法求解多约束匹配问题，匹配代价由距离、价值、续航、任务切换惩罚和阈值约束等子项加权构成，且权重可在线调节并模板化复用。  
4. 按分配结果进行状态切换，形成SEARCH、TRACK、PURSUIT、RETURN状态流转。  
5. 在追捕阶段设置稳定感知门控，仅当TRACK阶段Explorer满足连续感知判据时，启动N对1追捕子任务环境并调用预训练策略模型执行去中心化追捕。  
6. 在追捕子任务结束后执行资源回收、状态回切与重新分配，构成闭环执行。  
7. 在追捕阶段支持多决策倾向模型选择与切换，以满足不同任务偏好的动态调整。

进一步地，所述追捕阶段调用的预训练策略模型可来自现有N对1目标追捕技术方案；在本发明中该模型作为追捕执行组件使用，不构成本发明对所述既有训练方法本身的保护主张。

### （三）有益效果
本发明相对现有技术至少具备以下效果：
1. 将人工可解释优化决策与高动态策略推理结合，兼顾可控性与实时性。  
2. 通过权重化任务分配机制实现决策倾向可调、可复用。  
3. 通过稳定感知门控与异常回退机制，提高多阶段协同流程可靠性。  
4. 通过策略模型库切换机制，实现追捕阶段任务内决策风格调整。  
5. 对搜索航线形式不作限定，便于跨场景部署与工程扩展。

## 具体实施方式
为使本领域技术人员能够实施本发明，以下给出非限制性实施例。

### 实施例1：搜索阶段的人在环预规划
在任务初始化后，根据任务区域、无人机数量与安全参数生成覆盖式搜索方案。使用者可对覆盖率相关参数、边界安全参数、待命模式参数进行调整并重新规划。所述覆盖式方案可采用任意可实现区域覆盖的航线规划方式，本发明不限定具体几何结构。

### 实施例2：分配阶段的人在环优化
当Explorer发现新目标写入任务目标池，或追捕结束导致资源池释放时，触发任务分配。构建基于匈牙利算法的代价矩阵并求解最优匹配。代价子项至少包括距离、价值、续航、任务切换惩罚及阈值约束。使用者可在线调节各子项权重并重算，形成不同分配倾向；配置可保存为模板。

### 实施例3：追捕阶段门控启动与模型切换
根据分配结果将Explorer切换为TRACK，将Hunter切换为待追捕。仅当Explorer对目标达到连续稳定感知后，启动N对1追捕子任务环境。追捕控制由预训练策略模型执行。针对不同任务偏好可选择效率优先、稳健优先等模型，并允许任务内切换，切换后在下一控制周期生效且继承当前任务状态。

### 实施例4：异常回退与闭环执行
A1：TRACK中的Explorer发现新目标时，若存在空闲Explorer则立即触发新增分配；若无空闲Explorer则目标暂存并等待后续重分配。  
A2：被派遣Explorer接近目标过程中丢失目标且无其他Explorer可感知该目标时，终止该目标追捕启动流程，回收关联资源并删除临时目标记录。  
追捕子任务完成后，更新任务目标池与资源池，Explorer与Hunter回切到搜索或待命状态并触发下一轮分配。

以上实施例用于说明本发明而非限制本发明。本领域技术人员在不脱离本发明实质的前提下所作等同替换、组合或改进，均应落入本发明的保护范围。
